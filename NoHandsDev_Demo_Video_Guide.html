1. Pre-Recording Checklist (2 Minutes)

  • Open http://localhost:3000 (or your Vercel URL) in Chrome.
  • Ensure Wispr Flow is running in the background with hotkey active (Ctrl + Win).
  • Start your screen recorder (OBS Studio, Loom, or Windows Win + Alt + R).
  • Keep microphone close and speak clearly at a natural, energetic pace.

2. Minute-by-Minute Script & Action Plan

Timing On-Screen Action What to Say (Exact Script)
0:00 - 0:20 Show the NoHandsDev homepage. Point cursor at the hero title.
"Hey everyone! Developers spend over 40% of their day writing prose instead of coding — writing PRDs, typing backlog tickets, and leaving line-by-line code reviews. Typing is slow, which is why I built NoHandsDev: an end-to-end tool to plan, build, and review software entirely by voice using Wispr Flow."
0:20 - 0:50 Click into the Voice-to-PRD input box.
Hold Ctrl + Win and speak aloud (or click sample).
Click Decompose into PRD & Issues.
"Here is the first bottleneck: turning a brainstorm into tickets. I hold my Wispr Flow hotkey and describe a feature out loud: 'We need a Stripe checkout integration where workspace owners can invite teammates and manage seats...'
Wispr types it in seconds. I click Decompose, and NoHandsDev instantly turns my speech into a structured PRD, architectural API endpoints, and atomic GitHub issues with checklists ready to copy!"
0:50 - 1:20 Switch to Voice PR Review & Changelog tab.
Scroll the code diff.
Speak a review comment into the box.
Click Format Structured Review.
"Next is code review. Instead of typing nitpicks line by line, I inspect the git diff, hold my hotkey, and talk: 'In auth.ts line 32, wrap JSON.parse in try-catch to avoid crashing on corrupted Redis cache.'
It automatically tags the comment as a Bug or Security flag, and even auto-generates release notes and changelogs for the PR."
1:20 - 1:40 Switch to Wispr Insights tab or show your Wispr desktop app usage card.
"Every spec, prompt, and review in this project was created voice-first using Wispr Flow, cutting documentation time by 4x. Here is my active Wispr usage card from the desktop app."
1:40 - 1:55 Show the GitHub repository / Vercel link.
"NoHandsDev bridges conversational speech with developer tooling. The repository is open on GitHub, and the live link is in the description. Huge thanks to WeMakeDevs and Wispr Flow for the challenge!"
💡 Winning Tip for Judges: Mention that the app has a built-in "Judge 1-Click Demo" toggle at the top right so the judges (Kunal Kushwaha and Wispr team) can test it in 10 seconds without needing their own API keys!
